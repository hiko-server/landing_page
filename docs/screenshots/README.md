# Screenshots

Drop your own captures here using these filenames so the project README
picks them up automatically. Recommended dimensions are 1600×1000 (16:10)
for hero shots and 1600×900 for inline ones; PNG or JPG, < 600 KB after
compression.

| Filename | What to capture |
|---|---|
| `hero-light.png` | Full home page in light mode, scrolled to the [01] Introduction section |
| `hero-dark.png` | Same as above, in dark mode |
| `admin-storage.png` | `/admin/dashboard?tab=storage` — the inventory + backup panel |
| `admin-home.png` | `/admin/dashboard?tab=home` — Home editor with visibility checkboxes visible |
| `admin-cv-studio.png` | `/admin/dashboard?tab=cv` — CV Editor Studio split pane |
| `admin-versions.png` | `/admin/dashboard?tab=versions` — version-history rollback list |
| `cmdk.png` | ⌘K command palette open on the home page |
| `mobile-home.png` | Home page on mobile viewport (≤ 414 px wide) |

If a file is missing, the README still renders — the `<img>` tag just
shows the filename. Replace at your leisure.

> Heads-up: do not commit screenshots that include real names, email
> addresses, phone numbers, paid SaaS dashboards, or production URLs.
> Redact before saving. The whole repo is open-source.
