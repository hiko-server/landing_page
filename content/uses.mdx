## Editor

- **VS Code** — daily driver. Vim bindings, GitHub Copilot, Continue.dev for local LLM.
- **Cursor** — for agent-mode refactors on side projects.
- **JetBrains IntelliJ / WebStorm** — when the project is big enough that VS Code's TS server starts wheezing.

## Languages & runtimes

- **TypeScript / Node.js** — backend + Next.js work.
- **Python 3.11** — ML / RAG / data scripts (`uv` for env management, never `pip`).
- **Go** — sharp tools (CLI utilities, infra glue).
- **Rust** — learning; currently working through _Programming Rust_.

## Stack I reach for

- **Frontend:** Next.js (Pages Router still, App Router for greenfield), Chakra UI v2, Tailwind, Framer Motion.
- **Backend:** Node + Express / Next API routes, FastAPI when Python.
- **Data:** MongoDB (Atlas + self-hosted), Postgres, Redis for caches/queues.
- **ML:** LangChain / LangGraph, vLLM for self-hosted inference, OpenAI / Anthropic SDKs.

## Hardware

- **MacBook Pro 14" M3 Pro** — 36GB / 1TB. Primary dev machine.
- **Custom Windows desktop** — Ryzen 7 + RTX 4070, used for local LLM inference and gaming.
- **Keychron Q1 Pro** — wireless, Gateron Brown.
- **Sony WH-1000XM5** — daily headphones.
- **Logitech MX Master 3S** — mouse on desktop.

## Browser

- **Arc** — main browser. Spaces + command bar are non-negotiable now.
- **Chrome** — for DevTools when Arc misbehaves.
- **Firefox** — kept around for privacy-sensitive sessions.

## Terminal & shell

- **Warp** on macOS / **Windows Terminal** on PC.
- **zsh** + Starship prompt.
- **fzf**, **ripgrep**, **zoxide**, **eza**, **bat** — the usual modern-CLI loadout.
- **tmux** when I need persistent sessions on a remote.

## Productivity

- **Notion** — long-form notes, project specs.
- **Obsidian** — daily journal + zettelkasten.
- **Linear** — issue tracking for everything non-trivial.
- **Raycast** — launcher + clipboard history + window management.

## Services I pay for

- **GitHub Copilot + Claude Pro + ChatGPT Plus** — the three-LLM stack.
- **Vercel Pro** — site hosting + preview deploys.
- **Cloudflare** — DNS, R2, Tunnel.
- **1Password** — passwords + dev secrets.
- **Fastmail** — primary email (Outlook is forwarding-only).

## Self-hosted

- **Coolify** on a Hetzner CX32 for side-project Docker workloads.
- **Caddy** as reverse proxy / auto-TLS.
- **Uptime Kuma** for monitoring.
